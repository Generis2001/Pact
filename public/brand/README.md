# Pact logo assets

The connected calligraphic lettering is based on Lobster Two Bold Italic by Pablo Impallari, shaped with HarfBuzz and converted to SVG outlines. The logo needs no font download at runtime. The upstream font's SIL Open Font License is included in `OFL-LobsterTwo.txt`.

- `pact-logo.svg`: white lettering on the existing black badge, used in the sidebar and mobile header.
- `pact-wordmark.svg`: black lettering with a transparent background.
- `pact-icon.svg`: square black-and-white artwork for project profiles.
- `pact-icon.png`: 1024 × 1024 PNG export for uploads such as DoraHacks.
- `../favicon.svg`: the same lettering in the favicon's existing green-and-dark palette.

Source font: https://github.com/google/fonts/tree/main/ofl/lobstertwo
